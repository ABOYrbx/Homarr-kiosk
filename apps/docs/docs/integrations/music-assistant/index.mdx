Homarr reads player queues from Music Assistant over its WebSocket API. The always-on display (AOD) queue view uses this
connection to show the upcoming tracks.

### Adding the integration

<AddingIntegration />

Use the HTTP address of your Music Assistant server with its port, for example `http://music-assistant:8095`. The default
port is `8095`; Homarr connects to the `/ws` endpoint on that host.
